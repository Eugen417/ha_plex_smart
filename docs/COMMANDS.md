## ⚡ Как маршрутизируются команды (0 токенов против ИИ)

SmartPlex сам выбирает самый быстрый и дешёвый путь обработки:

| Тип команды | Задержка | Расход токенов ИИ | Механизм |
| :--- | :---: | :---: | :--- |
| **Управление активным плеером** *(пауза, стоп, перемотка ±сек/мин, переход на минуту, рестарт, следующий/предыдущий, повтор, микс)* | `< 1 мс` | `0` | Детерминированный парсер `extract_playback_control_intent` (в `plex_smart.command` и в `ChatLog` Assist) |
| **Чистый перенос между комнатами** *(«перенеси / переключи / верни фильм из зала в спальню», «обратно из спальни в зал»)* | `< 1 мс` | `0` | Детерминированный перехват `extract_pure_handoff_intent` (защищает от галлюцинаций ИИ) |
| **Прямой запуск по названию** *(«включи Интерстеллар», «продолжи Гангстерленд 2 сезон 8 серия», «включи микс Queen»)* | `< 1 мс` | `0` | Локальный резолвер по индексу библиотек в ОЗУ |
| **Смысловые и составные запросы** *(2+ актёра вместе, «похожее на X», свежие комедии, жанр + десятилетие)* | `~1–2 с` | ИИ | Нативные инструменты Assist (`plex_smart_*`) или `ai_task.*` (для `plex_smart.command`) |

## 🎬 1. Фильмы (`START` vs `RESUME`)

| Сценарий | Примеры фраз | Поведение SmartPlex |
| :--- | :--- | :--- |
| **Запуск с начала (`0:00`)** | *«Включи фильм Интерстеллар»*<br>*«Запусти Начало в зале»*<br>*«Включи Битву за битвой с начала»* | Находит точный `rating_key`, будит ТВ (холодный / тёплый / горячий старт) и запускает строго с **`0:00`** (`resume=0, offset=0`). |
| **Продолжить с места остановки** | *«Продолжи фильм Битва за битвой»*<br>*«Досмотри Дюну в спальне»*<br>*«Возобнови 2:22 с того места»* | Запрашивает живой `viewOffset` напрямую у Plex (`GET /library/metadata/{id}`), защищает прогресс от случайного затирания первыми секундами (`saved_resume_offsets` + `65с`-порог) и перематывает плеер на сохранённую точку. |
| **Запуск с конкретной минуты** | *«Включи Интерстеллар с 45-й минуты»*<br>*«Запусти Матрицу на 1:15:00»* | Передаёт явный `offset_sec` (`2700` / `4500`) и доводит плеер до нужной отметки. |
| **Совместные фильмы 2+ актёров (`AND`)** | *«Включи фильм, где вместе играют Ди Каприо и Брэд Питт»*<br>*«Найди комедию с Джимом Керри и Кэмерон Диаз»* | Строгое пересечение `актёр 1 ∩ актёр 2` по полной БД Plex (`async_intersect_people`) + двуязычное сравнение RU/EN имён и падежей. |
| **Похожее кино (`similar_to`)** | *«Включи что-нибудь похожее на Джентльмены»*<br>*«Поставь фильм в духе Интерстеллара»* | Использует нативный `GET /library/metadata/{id}/similar` (предпочитая непросмотренные) с локальным фоллбеком по жанрам, режиссёрам и актёрам. |
| **Фильтры и сортировка** | *«Включи свежую комедию»*<br>*«Поставь лучшую фантастику 90-х»*<br>*«Включи любой непросмотренный боевик»* | Поддерживает `genre`, `year`, `decade`, `director`, `studio`, `collection`, `unwatched`, `sort_order` (`newest`, `oldest`, `top_rated`, `random`). |

## 📺 2. Сериалы, сезоны и серии (`continuous: 1`)

Во всех запусках сериалов и серий автоматически включается `continuous: 1` (автопереход `PlayQueue` к следующей серии).

| Сценарий | Примеры фраз | Поведение SmartPlex |
| :--- | :--- | :--- |
| **Начать сериал с начала** | *«Включи сериал Гангстерленд»* | Запускает **`S01E01`** (пропуская спецвыпуски `Season 00`). |
| **Продолжить сериал** | *«Продолжи сериал Гангстерленд»*<br>*«Досмотри Во все тяжкие в спальне»* | Берёт активную серию из `Continue Watching` (или следующую непросмотренную) вместе с точным `viewOffset`. |
| **Конкретный сезон / серия** | *«Включи 2 сезон 8 серию Гангстерленда»*<br>*«Продолжи 3 сезон Друзей»* | Резолвит точный `rating_key` эпизода (`S02E08`), либо первую недосмотренную серию сезона. |
| **Случайная серия внутри сезона** | *«Включи случайную серию 2 сезона Друзей»* | Выбирает случайный эпизод строго внутри указанного сезона. |

## 🎵 3. Музыка, аудиокниги и плейлисты

| Сценарий | Примеры фраз | Поведение SmartPlex |
| :--- | :--- | :--- |
| **Исполнитель (микс по умолчанию)** | *«Включи Queen»*<br>*«Включи микс Кино в зале»* | Создаёт `PlayQueue` треков исполнителя с `shuffle=1` и `continuous=1`. |
| **Конкретная песня (даже без артиста)** | *«Включи песню Bohemian Rhapsody»*<br>*«Поставь трек Кукушка Кино»* | Ищет трек через `/hubs/search` по названию (и опционально по артисту/альбому). |
| **Альбом или аудиокнига** | *«Включи альбом Dark Side of the Moon»*<br>*«Продолжи аудиокнигу Дюна»* | При `resume=true` находит недослушанный трек/главу и продолжает ровно с сохранённой секунды. |
| **Жанр, настроение, десятилетие** | *«Включи танцевальную музыку»*<br>*«Поставь рок 90-х»* | Собирает очередь треков по `genre`, `mood`, `album.year`, `album.decade` со `shuffle=1`. |
| **Готовый плейлист Plex** | *«Включи плейлист Утро»*<br>*«Включи плейлист Тренировка вперемешку»* | Сохраняет исходный порядок треков (или перемешивает при словах *«микс / вперемешку / вразброс / случайно»*). |

## 🔄 4. Двусторонний перенос между комнатами (`HANDOFF`)

| Сценарий | Примеры фраз | Поведение SmartPlex |
| :--- | :--- | :--- |
| **Прямой и обратный перенос** | *«Перенеси фильм из зала в спальню»*<br>*«Переключи кино обратно из спальни в зал»*<br>*«Верни фильм в зал»* | 1) До выключения снимает живую позицию исходного ТВ (сессия PMS + стейт HA + `saved_resume_offsets`).<br>2) Параллельно выключает старый ТВ (`media_stop` ≤ 2.5с + `turn_off`) и будит целевой экран.<br>3) Запускает контент с откатом **−5 сек** (`handoff_rewind_sec`) и строго фильтрует `/status/sessions` по `machine_id` целевого ТВ (призрачная сессия погашенного ТВ не мешает перемотке). |
| **Перенос без указания исходной комнаты** | *«Перенеси просмотр в спальню»* | Автоматически находит комнату с активной сессией Plex и выключает её (если включён `turn_off_on_handoff`). |
| **Умное «Продолжи» без названия** | *«Продолжи»*<br>*«Продолжи просмотр»* | Если в активной комнате (например, в Спальне) плеер **стоит на паузе** — мгновенно снимает его с паузы (`media_play`) без перезапуска с `0:00` и без уноса в дефолтный Зал! Если ничего не активно — продолжает верхний элемент из `Continue Watching`. |

## ⏯ 5. Управление воспроизведением, перемоткой, повтором и миксом (`CONTROL`)

Если комната не указана, SmartPlex автоматически выбирает зону, в которой **прямо сейчас идёт или стоит на паузе воспроизведение**.

| Команда | Примеры фраз | Действие (`plex_smart.control`) |
| :--- | :--- | :--- |
| **Пауза** | *«Поставь на паузу»*<br>*«Пауза в зале»* | `action: pause` (одиночный вызов без двойного переключения: `plex_client` → PMS Companion → `hw_entity`; на Apple TV сразу `hw_entity`). |
| **Снять с паузы** | *«Сними с паузы»*<br>*«Продолжи»* *(когда на паузе)* | `action: resume_play` — мгновенное продолжение без перезапуска потока. |
| **Стоп** | *«Останови воспроизведение»*<br>*«Стоп в спальне»* | `action: stop`. |
| **Перемотка вперёд / назад (`±сек / ±мин`)** | *«Перемотай вперёд на 10 секунд»*<br>*«Отмотай назад на 5 секунд»*<br>*«Перемотай вперёд на 2 минуты»* | `action: seek_relative`, `delta_sec: 10` / `-5` / `120` (вычисляет `текущая позиция + delta_sec` и шлёт целочисленный `seekTo` / `media_seek`). |
| **Переход на точную минуту / таймкод** | *«Перемотай на 30 минуту»*<br>*«Перемотай на 1 час 15 минут»*<br>*«Перейди на 45:30»* | `action: seek_to`, `offset_sec: 1800` / `4500` / `2730`. |
| **Вернуть в начало (`0:00`)** | *«Перемотай в начало»*<br>*«Начни сначала»* / *«Заново»* | `action: restart` (`offset = 0`). |
| **Следующий / предыдущий** | *«Следующий трек»* / *«Следующая серия»*<br>*«Предыдущая песня»* | `action: next` / `previous` (строго через Plex-плеер, никогда не отправляя `KEY_CHUP` на ТВ). |
| **Повтор (`repeat`)** | *«Включи повтор трека»*<br>*«Поставь на повтор»*<br>*«Выключи повтор»* | `action: set_repeat`, `repeat: one` / `all` / `off` (`/player/playback/setParameters?repeat=1|2|0`). |
| **Микс на лету (`shuffle`)** | *«Включи микс»* / *«Перемешай очередь»*<br>*«Выключи случайный порядок»* | `action: set_shuffle`, `shuffle: true` / `false` (`/player/playback/setParameters?shuffle=1|0`). |

## 🔍 6. Поиск без включения ТВ и Кинорулетка

* **Поиск в библиотеке (`plex_smart_search`):** *«Какие у нас есть фильмы с Киану Ривзом?»*, *«Что я не досмотрел в Plex?»*, *«Найди комедии 2024 года»* — читает индекс и `Continue Watching` без пробуждения экранов.
* **Кинорулетка (`plex_smart.spin_roulette`):** подбор `1..6` непросмотренных фильмов с анти-повтором, коллаж постеров с крупными номерами и готовые кнопки для **VK Notify** и **Telegram Bot** (см. [`examples/README.md`](../examples/README.md)).

## 🛠 7. Примеры YAML для всех 6 служб SmartPlex

```yaml
# 1. Естественный язык (локально <1 мс или через ai_task.*)
action: plex_smart.command
data:
  command_text: "переключи фильм обратно из спальни в зал"

# 2. Структурированный запуск / возобновление / старт с точной минуты
action: plex_smart.play
data:
  zone: "Зал"
  media_type: movie
  title: "Интерстеллар"
  resume: false
  offset_sec: 1800

# 3. Перенос просмотра между комнатами
action: plex_smart.handoff
data:
  source_zone: "Спальня"
  target_zone: "Зал"
  turn_off_source: true

# 4. Пауза, перемотка ±сек, переход на минуту, повтор и микс
action: plex_smart.control
data:
  action: seek_to # pause | resume_play | play_pause | stop | seek_relative | seek_to | restart | next | previous | set_repeat | set_shuffle
  zone: "Зал"     # опционально: по умолчанию активная сейчас комната
  offset_sec: 1800 # для seek_to (30:00)
  # delta_sec: -10 # для seek_relative (-10 сек)
  # repeat: one    # для set_repeat (off | one | all)
  # shuffle: true  # для set_shuffle

# 5. Кинорулетка с коллажем и клавиатурами для VK/Telegram
action: plex_smart.spin_roulette
data:
  preset: "Вечернее кино"
  zone: "Зал"
response_variable: roulette

# 6. Принудительное обновление индекса библиотек
action: plex_smart.refresh_cache
```

### Инструменты Assist LLM API (`SmartPlex`)
После включения галочки **SmartPlex** в настройках вашего голосового агента Assist автоматически регистрируются 4 инструмента:
1. `plex_smart_play` — запуск и продолжение фильмов, сериалов, музыки, плейлистов, совместных работ актёров, похожих фильмов и старта с `offset_sec`.
2. `plex_smart_transfer_or_resume` — перенос между комнатами и продолжение `Continue Watching`.
3. `plex_smart_control` — пауза, снятие с паузы, стоп, перемотка `±сек/мин`, переход на минуту, рестарт `0:00`, `next`/`previous`, `repeat` и `shuffle`.
4. `plex_smart_search` — поиск по медиатеке и `Continue Watching` без включения ТВ.
